# Suggestions and contributions

This is my personal Hermes setup, shared in case it helps others. Ideas, bug
reports, adaptation questions and pull requests are welcome. I may use them,
but do not promise support, fixes, responses, releases or timelines.

Please include your Hermes version and OS, the behaviour you expected, and a
small reproduction or scrubbed screenshot. Do not include credentials, private
chat history, call transcripts or profile exports. For a larger change, open an
idea first so nobody spends time assuming it will be adopted.

Opening an issue or PR grants no repository write/merge permission. The owner
decides which changes to merge and publish. Automated merges are not used.

See [development notes](docs/DEVELOPMENT.md) for source/build/check instructions.
