# Working with Inner Circle

Read README.md, docs/INSTALL.md and docs/INTEGRATIONS.md before installing or
adapting this personal preset. Use the owner's current instructions.

- Inspect the actual Hermes version and existing plugins first. Preserve profile
  IDs, chats/history, personalities, credentials, schedules and routing.
- Use the native package installer. Back up presentation settings and overlapping
  plugins; never restore a whole config/database as an uninstall shortcut.
- The built desktop/plugin.js is the complete package. Do not install plugin.js
  alone or enable duplicate Bubble Mode/Task Dock/roster reskins.
- Adapt channel/activity metadata from native evidence. A prepared result is not
  delivered. Unknown or ambiguous metadata stays undecorated. Connecting an
  external service, syncing conversations or ingesting calls needs owner authority.
- Keep private adapters, credentials, conversation originals and configuration
  out of this public repository. Demo text is synthetic; artwork is credited.
- Edit readable sources, run npm run build and npm test, then verify the relevant
  native/browser behaviour. Do not claim cross-platform/native acceptance from
  a fixture alone. Document unmet catalog SDK requirements honestly.
- This is an as-is personal project. Suggestions are welcome; do not promise
  support, fixes or merge acceptance on the owner's behalf.
